## 사용 방법

클래식 교향곡은 같은 작품이라도 지휘자, 오케스트라, 판본과 연주 시간이 다르다.

- 아래 검색 링크에서 공식 오케스트라·음반사·공연기관 영상을 우선 선택한다.
- 검색 결과 URL은 `youtubeVideoId`로 저장하지 않는다.
- 최종 채택한 영상의 11자리 ID만 저장한다.
- 전체 교향곡 영상은 악장별 시작 시간을 직접 확인한다.
- 추천 악장이 별도 영상으로 제공되면 전체 영상과 구분한다.
- 지휘자, 오케스트라, 합창단, 독창자와 공연·녹음 연도를 기록한다.
- 영상마다 타임라인이 다르므로 최종 영상 확정 후 감상 가이드를 작성한다.
- 영상 다운로드나 음원 추출 기능은 제공하지 않는다.

## 영상 선정 우선순위

1. 오케스트라·지휘자·연주자의 공식 채널
2. 음반사 또는 권리 보유자의 공식 영상
3. 공연장·음악제·방송사의 공식 공연
4. 자동 생성 Topic 영상 중 크레딧이 명확한 항목
5. 검증된 음악 교육기관 채널

### 제외 권장

- 출처가 불분명한 재업로드
- 작곡가나 교향곡 번호가 잘못 표기된 영상
- 추천 악장의 시작 위치를 확인할 수 없는 편집 영상
- MIDI 또는 가상악기 재생을 실제 오케스트라처럼 표시한 영상
- 해설·광고·인트로가 지나치게 긴 영상
- 임의로 속도나 음정을 변경한 영상

- [ ] 공식 또는 권리 보유 채널인가?
- [ ] 영상이 현재 공개 상태인가?
- [ ] 로그인 없이 재생 가능한가?
- [ ] iframe 임베드가 허용되는가?
- [ ] 지역 제한이 없는가?
- [ ] 전체 영상의 악장 시작 시간을 기록했는가?
